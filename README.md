# Pawchi Blind Boxes
Tienda de blind boxes hecha con HTML, CSS y JavaScript

## Como abrir
1. Abre la carpeta en Visual Studio Code
2. Abre index.html con Live Server

## Contenido
La pagina incluye catalogo, detalle de productos, carrito, registro, login, blog, nosotros, contacto y administracion

- Los archivos HTML contienen las paginas
- estilos contiene el CSS
- scripts contiene el JavaScript
- img contiene las imagenes
