Nosotros

Pawchi Blind Boxes es una tienda academica de figuras coleccionables sorpresa. Cada caja pertenece a una coleccion y esconde un personaje distinto.

Nuestra idea

Crear una experiencia sencilla y alegre para descubrir, coleccionar e intercambiar personajes Pawchi.

Desarrollo

Este sitio fue construido por estudiantes con HTML5, CSS externo y JavaScript puro para la asignatura DSY1104.
